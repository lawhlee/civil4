# 민법4 객관식 학습

사무관리 3문항, 부당이득 25문항, 불법행위 32문항의 학습 사이트입니다.

- 개념형 35문항: 객관식 또는 선지별 O/X 162지문
- 추가 선지 O/X 157지문: 사무관리 1개, 부당이득 60개, 불법행위 96개
- O/X 합계 319지문. 추가 선지는 객관식 풀이를 제공하지 않습니다.
- 기존 문항 / 추가 선지 O/X / 모두 선택. 추가 선지의 원문 보기에는 해당 선지가 포함된 객관식 전체를 표시합니다.
- 사례형 25문항: 객관식
- 변호사시험 기출 / 모의고사 기출 / 모두 선택, 단원·유형·출제 순서·문항 수로 세트 구성
- O/X에서는 해당 선지의 해설 텍스트만 표시하고 답안지 원문 이미지는 전체 보존
- 브라우저에 학습 기록과 진행 위치 저장, 오답 복습 및 기록 내보내기·불러오기
- 답안 제출 전에도 이전·다음 문제로 이동. 선택한 답과 위치는 유지하고 건너뛴 문제는 미채점으로 처리
- 기존 문항 184개 판례 실재 확인, OCR 선고일 오류 2건은 원문과 공식 판례에 맞추어 정정
- 추가 선지 인용 판례 123개 중 122개는 공식 대조 기록 확인. 2016다12656은 공식 원문 미확인으로 별도 표시

## 추가 선지 검증

추가 선지 데이터는 `supplemental-ox.json`, 판례 확인 기록은 `supplemental-case-audit.json`에 있습니다. 원래 개념형 관련 선지 202개 중 승인된 제외 목록 45개를 적용한 157개이며, 정오 데이터와 원래 객관식 정답을 대조했습니다. 선지별 해설은 해당 부분만 발췌하고 원문 이미지는 객관식 문항 및 답안지 전체 범위로 제공합니다. 학습 기록 키를 유지하여 기존 기록 및 진행 세트를 이어 사용할 수 있습니다.

검증: `node scripts/check.cjs` 및 `node scripts/check-supplemental.cjs`.

## 2026-11-11 OCR 정정

문제·해설의 확인된 OCR 오인식과 사건번호·선고일을 정정했습니다. 수정 전후 차이는 이 저장소의 OCR 정정 커밋에서 확인할 수 있습니다. 객관식 원문 이미지, 문제 ID, O/X 정오 및 학습 기록 키는 유지합니다. 교재 자체의 당사자 역전 표기(`civil_mock_5_045` ①)는 2026-11-12 정정했으며 해당 해설과 원문 보기에 사유를 표시합니다.

## 2026-11-12 추가 정정

남은 OCR 오인식과 훼손된 문장을 원문 이미지에 맞추어 복원했습니다. `civil_mock_5_045` ①의 부당이득 반환채권은 임대인 甲의 임차인 乙에 대한 채권으로 정정하고 정정 사유를 표시합니다. 선고연도 오인식 및 사건번호 숫자 누락도 정정했습니다. 기존 문제의 누락 인용 2011므2997을 공식 원문 확인 목록에 추가했으며, 2016다12656은 공식 원문 미확인 표시를 유지합니다.

검증: `node scripts/check.cjs`, `node scripts/check-supplemental.cjs`, `node scripts/check-corrections.cjs`.

## 2026-11-12 띄어쓰기 정정

O/X 해설 111곳의 줄 경계를 대조하여 단어·인용번호 중간의 강제 줄바꿈과 띄어쓰기·중복 공백을 정리했습니다. `civil_mock_4_055` ⑤의 해설에서 분리·누락된 문장 조각도 답안지 원문에 맞추어 복원했습니다. 정확히 일치하는 원문에만 `text-spacing.js`의 표시 규칙을 적용하며 문단·조문·목록 구조를 유지합니다. 원문 이미지, 문항 ID, 정오 및 학습 기록 키는 바꾸지 않습니다.

추가 검증: `node scripts/check-spacing.cjs`.
