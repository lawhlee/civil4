# civil4 · 민법4 판례·조문 OX

기출문제 추가 전의 민법4 학습 페이지로 복원한 정적 사이트입니다.

- 판례 OX 265문항
- 민법 조문 OX 155문항
- 전체 420문항, 유형별 선택 및 혼합 학습
- 오답노트, 북마크, 학습 통계, 중요도, 원문·출처·해설
- 모바일 반응형 화면

## 실행

저장소 루트의 `index.html`이 시작 페이지입니다. 별도 빌드나 설치 의존성이 없는 정적 사이트이며 GitHub Pages의 저장소 하위 경로에서도 사용할 수 있습니다.

로컬에서 실행하려면 저장소 폴더에서 다음 명령을 실행한 뒤 `http://localhost:8000`을 여세요.

```sh
python -m http.server 8000
```

## 학습기록

기록은 브라우저의 해당 사이트 저장 공간에 보관됩니다. 기존 사이트와 다른 도메인 사이에서는 자동 공유되지 않습니다. 기존 사이트의 **학습기록 → 백업 내려받기**를 이용하고 새 사이트에서 **백업 불러오기**를 선택하면 기록을 옮길 수 있습니다.

기출 문제를 포함한 이전 백업에서도 현재 420문항의 풀이 기록과 북마크는 유지됩니다. 제외된 기출이 포함된 이어풀기 세션은 종료되며, 판례·조문만 포함된 세션은 계속 사용할 수 있습니다.
