# 민법4 객관식 학습

사무관리 3문항, 부당이득 25문항, 불법행위 32문항의 학습 사이트입니다.

- 개념형 35문항: 객관식 또는 선지별 O/X 162지문
- 사례형 25문항: 객관식
- 변호사시험 기출 / 모의고사 기출 / 모두 선택, 단원·유형·출제 순서·문항 수로 세트 구성
- O/X에서는 해당 선지의 해설 텍스트만 표시하고 답안지 원문 이미지는 전체 보존
- 브라우저에 학습 기록과 진행 위치 저장, 오답 복습 및 기록 내보내기·불러오기
- 183개 판례 실재 확인, 인용일 불일치 2건은 별도 주석

## 배포
